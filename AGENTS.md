# KARMA SYSTEM

Используй ES Modules и один Node-процесс. Схему меняй версионированными миграциями. Храни Discord ID строками. Привязывай чтение объектов к серверу, каждое действие к полномочиям на объект. Для постоянных панелей используй маршрутизируемые custom_id. Не сохраняй секреты. Обрабатывай внешние эффекты отдельно от синхронных транзакций SQLite. Перед сдачей запускай npm run check, npm test и npm ls --omit=dev. Результаты и пробелы заноси в PROGRESS.md.
